SurveyQL playground

Sources name · survey · responses — each row is a dataset variable; the first is the default
Language cheat sheet 
load <survey> [<responses>]         paths or URLs; let b = load … binds a source without changing the default
questions() / sources()             list questions / list loaded datasets
avg|sum|min|max|median(q[, dp])     numbers; add: where gender is "female", by gender; dp = decimal places
count(all | q)                      row count or frequency table
get avg(income), count(all) by gender   several measures in one table
filter age > 30 | avg(income)       pipes narrow the data
sample(5) / show(10)                preview rows
draw bar|vbar|pie|doughnut(q)       charts; draw hist(q, bins); draw gauge(q)
draw bar(a, b) against key          series per key; with line(c, right) for combined charts
let adults = filter age >= 18       variables; then: adults | avg(income)
union(a, b) / join(b) on key        combine sources; use b; rename q as name
where x between(25, 40) and y is "z"  expressions: and or not in is contains between
indent a line, or start it with with / against / where / by / |   to continue the statement above
`Name with spaces`                  backticks for odd question names
colors.red / features.price         sub-fields of checkbox and matrix questions
